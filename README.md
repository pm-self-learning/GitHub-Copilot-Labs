# GitHub Copilot Workshop

Hands-on workshops for building repeatable engineering workflows with GitHub Copilot.

## Azure platform engineering with Terraform

Build a reusable Azure Storage module using repository instructions, Plan Mode,
Agent Mode, GitHub Actions, and an Agent Skill.

**Five labs, 40 minutes. No Azure subscription, credentials, or deployment required.**

| Lab | Capability | Duration |
| --- | --- | --- |
| [1. Define Azure Terraform standards](labs/azure-terraform/01-custom-instructions.md) | Custom Instructions | 5 min |
| [2. Design the infrastructure](labs/azure-terraform/02-plan-module.md) | Plan Mode | 5 min |
| [3. Build the Terraform module](labs/azure-terraform/03-build-module.md) | Agent Mode | 10 min |
| [4. Automate validation](labs/azure-terraform/04-validation-pipeline.md) | Agent Mode and GitHub Actions | 10 min |
| [5. Create and use a review skill](labs/azure-terraform/05-review-skill.md) | Agent Skills | 10 min |

Start with the [workshop setup](labs/azure-terraform/README.md).
Presenters can use the [facilitator guide](labs/azure-terraform/FACILITATOR.md)
and [reference solution](labs/azure-terraform/solution/README.md).
